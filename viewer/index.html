Connect this page to GitHub

To run months from this page, paste a GitHub token that can only start this repo's simulation. It is stored in this browser only (never on the website or in the repo). You do this once per device.

  1. Open GitHub → new fine-grained token.
  2. Name it e.g. worldleaders runner, pick an expiry.
  3. Repository access: Only select repositories → Worldleaders.
  4. Permissions → Repository permissions → Actions: Read and write. Nothing else.
  5. Generate, copy, paste below.
